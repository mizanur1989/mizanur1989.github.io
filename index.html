📖 What is SaintsReborn?

SaintsReborn (formerly known as SaintsRowPC) is an unofficial native Windows port of the classic Saints Row game from Xbox 360 (2006). Instead of using an emulator, this project statically recompiles the original PowerPC code to x86-64 using the ReXGlue SDK. This means you get a smooth, native performance that feels like a real PC game.

This project is completely legal and respects copyright – this repository contains no game code or data. You build the game yourself from your own original disc, ensuring you own everything you play.

🌐 Co-op Multiplayer

One of the best features of SaintsReborn is the built-in co-op multiplayer. You can play the entire story campaign or free roam with a friend. Three connection options are available:

  • 🏠 LAN – Play over your local network
  • 🔗 Direct IP – Connect directly to a friend's IP address
  • 🔑 Join Code – Use a simple code for online play

Everything is designed to be simple and user-friendly. No port forwarding knowledge required for the join code option.

🔧 System Requirements

While exact specifications can vary, SaintsReborn is optimized for modern PC hardware. For the best experience:

  • 🖥️ Operating System: Windows 10 or Windows 11 (64-bit)
  • 💾 Processor: Any dual-core or better x86-64 CPU
  • 🎮 Graphics: Dedicated graphics card recommended (integrated works too)
  • 💽 Storage: At least 10 GB free space (plus game data from your disc)
  • 🗜️ RAM: 8 GB or more recommended

Since the game is a native port, it runs significantly better than emulation on equivalent hardware.

🛠️ Troubleshooting Help

Most issues you might encounter have simple solutions:

  • ⚠️ Game won't start: Make sure your Windows is fully updated and you have the latest DirectX runtime installed
  • 📁 Build errors: Ensure your game disc is clean and compatible (original Xbox 360 version, not the remaster)
  • 🌐 Co-op connection issues: Try using the join code method, or check your firewall settings for the game
  • 🎵 No audio: Update your sound drivers and check that your default playback device is set correctly
